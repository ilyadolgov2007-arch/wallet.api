# Wallet

Учебный проект для учёта личных финансов на C#. Сейчас это консольное приложение с моделью банковского счёта: пополнения, списания, история операций и отчёты по расходам. Проект развивается поэтапно и в дальнейшем станет веб-API с базой данных.

## Возможности

- Пополнение и списание средств со счёта с указанием категории и даты
- Защита от некорректных операций: нельзя списать больше, чем есть на счёте, или провести операцию с нулевой или отрицательной суммой
- Неизменяемая история операций: баланс и список транзакций нельзя изменить в обход методов счёта
- Отчёты:
  - общая сумма доходов и расходов
  - расходы по категориям
  - самая крупная трата
  - операции за выбранный период

## Технологии

- C#
- .NET 10
- LINQ

## Как запустить

Нужен установленный [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
git clone https://github.com/ilyadolgov2007-arch/wallet.api.git
cd wallet.api/Wallet
dotnet run
```

## Структура

- `Account.cs` — счёт: баланс, история операций, бизнес-правила и отчёты
- `Transaction.cs` — одна операция: сумма, категория, дата и тип
- `TransactionType.cs` — тип операции: доход или расход
- `Program.cs` — демонстрация работы
